# Security

Counter Utility Matrix runs on your own machine, against public sources
and your own Claude Code subscription. You run it at your own risk.

The author makes no security commitment: no warranty, no support, no
promised response time, no duty to fix. The software comes as is, as the
license states. Whoever runs it is responsible for their own deployment -
the machine it runs on, the network it listens on, the sources it pulls
from, the accounts it uses - and for keeping it secure on their own terms.

The measures the code takes are described in [docs/security.md](docs/security.md)
for information only: a description of what the code does, not an
assurance that it is enough for you.

To report a vulnerability, contact the repository owner privately - a
GitHub private vulnerability report, or a direct message - rather than
opening a public issue.
