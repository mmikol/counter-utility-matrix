# Security

Countrix runs on your own machine, against public sources and your own
Claude Code subscription. You run it at your own risk.

The software comes as is, as the license states: no warranty, no support,
no promised response time, no duty to fix. Whoever runs it is responsible
for their own deployment: the machine, the network it listens on, the
sources it pulls from, the accounts it uses.

[docs/security.md](docs/security.md) describes what the code does. It is
not an assurance that it is enough for you.

Report a vulnerability privately: a GitHub private vulnerability report,
or a direct message.
